#Микро шпора по гиту
---
Когда уже всё настроил (в плане кнфигурации своего камаза полного гов...)
И тебе нужно создать локальный репозиторий на компе, а потом его запушить в гитхаб, тогда короче говоря делаешь так:

1. Открываешь гит баш
2. Заходишь используя cd и ls в папку, которая тебе нужна
3. Там создаешь папку, которая у тебя будет репозиторием mkdir
4. Заходишь в папку
5. Там пишешь git init
6. Можешь добавить файлик touch README.md
7. Затем чекнуть статус git status
8. Потом зафиксировать git add README.md (или --all)
9. Потом комитишь git commit -m "Создал локальный репозиторий"
10. Заходишь на гитхаб и там создаешь репозиторий
11. Копируешь SSH и в консоли пишешь git remote add <название> <SSH сылочка>
12. Чекаешь появилась ли связь с удаленным репозиторием git remote -v
13. Потом пушишь git push -u <название> master (или main)
14. В последующие разы работы с этим репозиторием делаешь п.8, п.9 и git push без всякой фигни
